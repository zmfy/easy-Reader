# OPDS 书目源 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供 OPDS 1.2 书目源，让手机 / iPad / 墨水屏上的阅读 App 用专用 OPDS 密码浏览、搜索、下载整个书库（TXT / UMD 转 EPUB）。

**Architecture:** 新增 `/opds` 路由（HTTP Basic，独立于 JWT），由「凭据服务 → Basic 中间件 → 目录查询 → Atom XML 生成 → 下载（原文件 / 修正版 EPUB / 转换 EPUB 缓存）」几个独立模块组成；网页端新增「阅读 App（OPDS）」页面和用户管理里的 OPDS 列。

**Tech Stack:** Express 4 + better-sqlite3 + bcryptjs + adm-zip（改为直接依赖）+ p-limit；Vue 3 + Element Plus；jest（后端）/ vitest（前端）。

**Spec:** `docs/superpowers/specs/2026-11-21-opds-design.md`

## Global Constraints

- 只在看书版（main 上的 `feature/opds` 分支）开发；新代码放独立文件，公共文件（`index.ts`、`db.ts`、`routes/settings.ts`、`Settings.vue`、`DefaultLayout.vue`、`router/index.ts`）只做接入改动。
- OPDS 1.2（Atom XML），不做 2.0、不做 KOSync、不做 PSE。
- feed 内所有链接为以 `/` 开头的绝对路径，不含主机名。
- 可见书 = `status IS NULL OR status NOT IN ('duplicate','garbled','damaged')`（与书库列表默认条件一致）。
- OPDS 密码：系统随机生成 16 位，字母表排除易混字符 `0 O o 1 l I`；只存 bcrypt 哈希；只在生成时返回一次。
- 作废规则：用户重置 OPDS 密码 / 用户或管理员关闭 / 管理员重置登录密码 → 作废；删除用户 → 删除；用户改登录密码、管理员改角色 → 不影响。不与 `token_version` 挂钩。
- 认证失败一律 401 + `WWW-Authenticate: Basic realm="easyReader"`；`must_change_password` 的账号也按 401 处理。
- 下载不写阅读历史 / 进度。
- 测试不连外网；后端测试写在 `backend/tests/**`，沿用 `tests/routes/history.test.ts` 的写法（临时 `DATA_DIR` + `app.listen(0)` + `fetch`）。
- 本地实测起后端时加 `USAGE_STATS=off`。
- 提交信息结尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`；不推送。

## Review Focus

1. **中文书名 / 作者里有 `&`、`<`、引号**：feed 必须是合法 XML，EPUB 的 OPF / XHTML 必须合法 —— Task 4、Task 6 各加转义测试。
2. **`Content-Disposition` 中文文件名**：要同时带 ASCII 兜底 `filename="book.epub"` 和 `filename*=UTF-8''…`，否则部分客户端下载失败 —— Task 8 测试。
3. **同一本书被两个设备同时下载（首次需转换）**：只转换一次，两个请求都拿到完整文件，缓存里没有半截文件（写临时文件再 rename）—— Task 7 测试。
4. **`file_path` 指向书库外（符号链接）或文件已被删除**：下载返回 404，不读库外文件 —— Task 8 测试（复用 `resolveRealPathInsideRoot`）。
5. **GBK 编码的 TXT**：转换后的 EPUB 与 TXT 下载都是 UTF-8 且无乱码 —— Task 7 测试用 GBK fixture。

- 规则：
  - 缓存目录 `path.join(DATA_DIR, 'opds-cache')`；转换结果文件名 `<bookId>-<sha1(key).slice(0,12)>.epub`，`key` = `[CONVERTER_VERSION, mtimeMs, size, title, author, summary, cover_url, JSON.stringify([...getOverridesMap(id)])].join('\n')`；生成成功后删除同一 `bookId-` 前缀的其他缓存文件。
  - 先写 `<name>.tmp-<random>` 再 `renameSync`；同一 key 的并发请求共用一个 Promise；全局 `pLimit(2)`。
  - EPUB 原书：先用 `EpubParser` 加载，`repaired === false` 时直接返回原文件路径；`repaired === true` 时把 `repairZipEndRecord(readFileSync)` 写入缓存（key 规则同上）并返回。
  - TXT 的 `txt` 下载：`iconv.decode(原文件, detectEncoding(path))` 去 BOM 后写 UTF-8 缓存（`.txt`）；原本就是 UTF-8 时直接返回原文件。
  - 转换 EPUB 的封面：`cover_url` 指向 `/covers/` 下的 jpg/png/webp/gif 且文件存在时读入，否则无封面。
  - `fileName`：`<显示书名>[ - <作者>].<ext>`，去掉 `/\\:*?"<>|`。
  - `mimeType`：epub `application/epub+zip`，pdf `application/pdf`，txt `text/plain; charset=utf-8`。
