# 全站界面风格统一 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按设计文档的规则统一全站界面：Element Plus 接入主题、通用布局类、设置页方案 B、各页去写死颜色与统一页头/卡片/按钮/图标。

**Architecture:** 先在 `frontend/src/assets/styles/main.css` 完成全局 token、Element Plus 变量映射与通用类（`.page` `.page-header` `.page-title` `.section-card` `.section-actions` `.note` `.form-grid` `.segmented` `.empty-state`），并抽 `PageHeader.vue`；再逐页替换。全部为样式与模板结构改动，不改业务逻辑。

**Tech Stack:** Vue 3 + Element Plus + Tabler icons；Vitest；vue-tsc；vite build。

**Spec:** `docs/superpowers/specs/2026-11-06-ui-unify-design.md`（规则表为准）。盘点截图与逐页问题：`/tmp/claude-1000/-home-zhangjq-projects-easyReader/3a4530f1-f982-4cf4-b5ef-360ee9d81800/scratchpad/style-audit/`（截图 01–42）。

## Global Constraints

- 只改样式与模板结构，不改功能、接口调用、交互流程与文案含义（重复标题删除、emoji 换图标属于允许的文案调整）。
- 颜色一律取主题变量或基于变量的 `color-mix`；不得新增写死的十六进制 / rgba 主题色（例外：封面遮罩、PDF 白纸、主题预览色卡、导图语义色）。
- 图标只用 `@tabler/icons-vue`（stroke-width 1.75；尺寸 14/16/18/20）；不新增依赖。
- 6 个主题（indigo、dark、warm、cool、sky、paper）都要可读；手机 390 宽无横向滚动。
- 每个任务：`cd frontend && npx vitest run && npx vue-tsc --noEmit && npx vite build` 通过；用开发服务（后端 3000 数据副本、前端 vite 5175）截图回归：靛青、暗夜、素纸三个主题 + 手机宽度，截图存 `scratchpad/ui-unify/task-N/`。
- 在 main 实现 Task 1–9；Task 10 在 study 上做（合并 main 之后）。

## Review Focus

1. **深色主题**：全局输入框改白底后，暗夜 / 烛光 / 冷月下 `--input-bg` 必须是深色而不是白色（Task 1 截图）。
2. **阅读器**：全局按钮 / 控件尺寸变化不得破坏阅读器工具栏、设置面板与目录抽屉布局（Task 1、Task 8 截图）。
3. **表格与弹窗**：EP 变量映射后表格 hover、选中、斑马纹与弹窗遮罩在深色主题下可读（Task 1、Task 3）。
4. **设置页功能不回退**：分段标签切换、`?tab=ai` 跳转、各 tab 保存、AI 配置警告、系统提醒开关、更新说明折叠都仍可用（Task 2）。
5. **手机**：分段标签横向滚动、表单 1 列、卡片 padding 16（Task 1、2）。
