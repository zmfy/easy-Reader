# PWA 第一期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 简单书房可安装到桌面、全屏打开并直接进入上次读的书；有「安装到桌面」入口、新版本提示与没网提示。

**Architecture:** 后端提供动态 Web App Manifest（名称取 `site_name`）与「上次读的书」接口。前端用 `vite-plugin-pwa`（只生成 Service Worker，预缓存应用外壳，manifest 由后端提供），新增 `/continue` 路由作为启动地址，登录页支持回跳；用户菜单加「安装到桌面」，App 根部挂新版本提示与没网提示。

**Tech Stack:** Node + Express + better-sqlite3 + jest；Vue 3 + Vite 5 + vite-plugin-pwa 1.3.0 + Element Plus + vitest（happy-dom）。

**Spec:** `docs/superpowers/specs/2026-11-08-pwa-design.md`

## Global Constraints

- 分支 `feature/pwa`（基于 `main`）；完成后合入 `main`，再合并进 `study`。不碰学习版独有文件。
- 依赖：`vite-plugin-pwa@1.3.0`（精确版本，devDependencies；兼容 vite 5），安装用 npm（锁文件 `frontend/package-lock.json`，resolved 地址须为 registry.npmjs.org）。
- 应用名称：`site_name`，为空时「简单书房」。`start_url` `/continue`，`scope` `/`，`display` `standalone`，`theme_color` `#4338ca`，`background_color` `#eef1f6`，`lang` `zh-CN`。
- Service Worker 不拦截 / 不缓存：`/api`、`/covers`、`/manifest.webmanifest`、`/health`，也不预缓存 `pdfjs/**`（cmaps、字体等大资源）。
- 作用范围：所有 HTTPS 访问者（及 localhost）都注册 Service Worker、显示两个提示。
- UI 文案（逐字）：「安装到桌面」「有新版本，点击刷新」「没有网络连接」「重试」「需要通过 HTTPS 访问才能安装到桌面」「点底部的分享按钮 → 选择『添加到主屏幕』」「当前浏览器不支持安装，请使用 Chrome、Edge 或 Safari」。非 HTTPS 提示附链接「查看说明」→ `https://easyreader.ucool.uk`。
- 「上次读的书」= 当前用户 `reading_progress.updated_at` 最新、且 `books` 中仍存在的记录；不判断是否读完。无 → 进 `/shelf`。
- 登录回跳只接受站内路径（以 `/` 开头且不以 `//` 开头），否则回 `/library`。
- 颜色用主题变量，UI 图标用 Tabler；应用图标为自绘 SVG（打开的书 + `#4338ca`）。
- 对外 API 只加不改，新接口写进 `docs/api.md`。

## Review Focus

1. **新版本部署后**：旧页面能看到「有新版本，点击刷新」，点击后确实加载新资源，不出现新旧资源混用白屏。→ Task 3 Step 5 浏览器验证（构建两次、改动后刷新）。
2. **Service Worker 吞掉 API / 封面请求**：断网与联网下 `/api` 请求都直达网络，登录、续期不受影响。→ Task 3 测试 `workbox config excludes api, covers, manifest and pdfjs`。
3. **登录过期时从桌面图标打开**：先到登录页，登录后回到 `/continue` 再进书；恶意 `redirect=//evil.com` 不得外跳。→ Task 4 测试 `safeRedirect rejects external targets`、`guard sends unauthenticated users to login with redirect`。
4. **上次读的书已被删除**：不进坏页面，跳过它取下一条，都没有就进书架。→ Task 1 测试 `getLastReadBookId skips deleted books`。
5. **网站名称含特殊字符 / 很长**：清单仍是合法 JSON、`short_name` 不超过 12 字。→ Task 1 测试 `buildManifest clips short_name and falls back to 简单书房`。
