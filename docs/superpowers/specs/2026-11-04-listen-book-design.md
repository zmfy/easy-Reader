# 听书（MiniMax 语音合成）设计

自用书房，主要场景：通勤（锁屏 / 后台继续播放）、睡前（定时停止）。浏览器自带语音不像真人，改用 MiniMax 语音合成。

## 设置
- AI 插件设置 → MiniMax 新增：听书功能（开 / 关，默认关）、听书模型（speech-2.8-turbo 默认 / speech-2.8-hd）、听书音色（精选约 10 个适合念小说的系统音色，默认「电台男主播」）。
- 听书是否可用与当前选中的 AI 插件无关：MiniMax 的听书开关为开且填了 Key 即可用。`/settings/ai-status` 返回 `tts_enabled`。

## 合成接口
- MiniMax `POST https://api.minimax.cn/v1/t2a_v2`，非流式，mp3 / 24kHz / 64kbps / 单声道；响应 `data.audio` 为 hex，`base_resp.status_code` 非 0 视为失败。
- 计费：turbo 2 元 / 万字符，hd 3.5 元 / 万字符，1 个汉字算 2 字符（约 6 元 / 10 元每小时）。
- 后端 `POST /api/reader/:bookId/tts { text }`（≤ 600 字）返回 audio/mpeg。按 sha1(模型 + 音色 + 文本) 缓存到 `DATA_DIR/tts-cache/<bookId>/`，同一段重听不再花钱；同一段并发请求只合成一次；删书时删除该书缓存目录。

## 播放（前端）
- 分段在前端按渲染出的段落（与阅读位置同一套段落）做：短段合并、长段按句子拆分，每段 ≤ 约 180 字，记录对应段落范围用于高亮。
- 从当前阅读位置所在段落开始；从章首开始时先念章节标题。
- 正在念的段落高亮，不在视口内时自动滚动；章末自动进入下一章；全书结束停止。
- 边念边预取后面 2 段。语速 0.8–2 倍用 `playbackRate` 本地调整，不重新合成。
- 锁屏 / 后台：单个 `<audio>` 元素连续换源播放；Media Session 显示章节与书名，支持播放 / 暂停 / 上一段 / 下一段。首次点击播放时同步解锁音频（iOS）。
- 定时停止：15 / 30 / 60 分钟或「本章结束」，到点音量渐弱后暂停。
- 用户手动换章时，从新章节开头继续念。

## 不做
- 不做流式合成、角色分配多音色、本地 TTS 模型；缓存不设容量上限（每小时约 30MB，后续需要再加清理）。
