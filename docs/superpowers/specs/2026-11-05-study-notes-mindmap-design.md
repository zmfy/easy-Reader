# 学习笔记：划线批注 + AI 知识导图 + 复习（设计）

## 为什么做

市面上的笔记 App 很多，单纯的划线/批注没有特色。本项目的书一类用于娱乐、一类用于**学习**；这个功能面向学习：
读者每划一条线，AI 就帮他从这一点**发散**出相关知识（例：读《史记》划线「项羽」→ 楚汉之争、鸿门宴、刘邦、韩信、范增……），
读者挑有用的留下，日积月累形成**整本书的学习导图**，再通过 **AI 出题 + 遗忘曲线**复习。
目标是让用户在这里沉淀「带不走」的学习成果，越用越离不开。

## 目标

1. 在阅读器中选中文字即可划线，可附批注。
2. 对任一划线点「AI 展开」，得到以它为中心的小导图（候选节点），用户挑选保留。
3. 每个节点可以：**继续展开**下一层；如果书中出现过该词，**跳回原文**对应章节与位置。
4. 每本书一张**总导图**：以书的目录结构为骨架，保留下来的小图挂在对应章节下；可拖拽、缩放、折叠；可导出。
5. **复习**：浏览总导图；AI 根据已保留节点出题，判对错并解释；错题按遗忘曲线安排再次复习。

## 不做 / 反目标

- 不让 AI 自动往导图里塞东西——**只有用户点了「保留」的才进导图**（反目标：导图被 AI 噪音淹没）。
- 不在打开阅读器或划线时自动调用 AI；只有点击「AI 展开」/「出题」才调用（与现有 recap/ask 一致，控制费用）。
- 不让 AI 判定「出处在第几章」——出处由系统在书中实际检索（AI 记章节容易错，反目标：点 📖 跳到错误位置）。
- 不做多人共享导图、协作编辑、公开分享链接；导出文件由用户自行发送。
- 不做向量检索；不把整本书发给 AI。
- v1 不支持 PDF 划线（PDF 以 canvas 渲染，无可选文本层）。PDF 书的导图页仍可手动加节点。（我的决定）
- 不区分「学习书 / 娱乐书」开关：功能对所有书可用，但只在用户主动点击时出现，不打扰小说阅读。（我的决定）

## 用户流程与界面

### 1. 划线与批注（阅读器内）
- 选中文字 → 浮出小菜单：「划线」「批注」「AI 展开」。
- 划线以底色标出；点已有划线可：编辑批注、AI 展开、删除。
- 「摘抄」不单独建模：划线本身就保存了原文，等同摘抄。（我的决定）
- 阅读器侧边新增「笔记」入口：列出本书全部划线/批注，按章节排序，点击跳转原文。

### 2. AI 展开小图（阅读器内）
- 布局（用户决定）：**电脑 = 右侧抽屉**，与原文并排；**手机 = 底部面板**，半屏看候选、可上拉全屏。按屏宽自动切换，内容与操作一致。
- 中心节点 = 划线文字；AI 返回两类候选：**事件/概念**、**人物**，每次约 5–8 个，每个附一句话说明。
- 候选节点虚线显示；点候选：「保留」「继续展开」「跳原文 📖」（仅书中有出处时显示）。保留后变实线，写入该书导图。
- 「继续展开」以该节点为新中心再请求一次 AI，结果作为它的子候选，可无限层。
- 未保留的候选树只存在于前端当前面板状态中，关闭面板即丢弃（不入库）。保留一个深层候选时，**自动连同它到中心节点的祖先链一起保留**，保证 `parent_id` 有效。（我的决定）
- 用户可在导图中**手动加节点、改名、删节点、给节点写批注**。（我的决定）

### 3. 出处检索（📖 跳原文）
- 对每个候选节点的名称，在本书章节正文中做本地文本检索（可复用 `ai-reading.ts` 的正文整理与关键词检索思路），找到首个/最相关的出现位置（章节 + 段落）。
- 有命中才显示 📖；点击跳到该章并定位到命中段落。
- 检索范围（用户决定）：**全书搜索**。出处在阅读边界之后的，显示为「📖 后文·<章节名>」并用弱化样式，由用户自己决定是否点击；在边界之前的显示普通 📖。

### 4. 总导图页
- 布局（用户决定）：**经典导图画布**（类 XMind），可拖拽、缩放、折叠。
- 拖拽 = 平移画布，**不改变节点位置**；布局自动计算，不保存坐标。v1 不支持拖拽改挂父节点（需要时删了重加）。（我的决定）
- 骨架 = 书的目录：根节点为书名，下面按 `getChapters()` 的 `level` / `groupTitle` 构成层级（如 史记 → 本纪 → 项羽本纪）。没有多层目录的书就是 书名 → 章节。
- 用户保留的节点挂在**划线所在章节**下（由划线产生的节点）；手动添加的节点挂在用户选择的位置。
- 没有笔记的章节/分组灰显；工具栏提供：折叠全部、「只看有笔记的章节」（默认开启，避免几百章撑爆画布）、导出、开始复习（带「N 题待复习」角标）。
- 入口：书籍详情页 + 阅读器侧边栏。

### 5. 复习
- **浏览复习**：在总导图上逐个看节点，任何节点可跳原文、继续展开。
- **AI 出题**：
  - 题目只基于**已保留节点**及其关联原文/批注，不考没学过的内容。
  - 题型：简答题为主，可含选择题；用户作答后 AI 判对错并给解释与原文出处。（题型细节为我的决定，可由实现者调整）
  - 题目生成后存库复用，不每次重新生成；节点被删除时其题目一并删除。
- **遗忘曲线**（用户决定要记错题、按遗忘曲线优先）：
  - 每道题有复习阶段；答对进入下一阶段，间隔约 **1 → 2 → 4 → 7 → 15 天**；答错回到第一阶段（次日再考）。（间隔为我的决定）
  - 「开始复习」优先出到期的错题，其次到期题，再次从未考过的节点补充新题；每轮题量默认 10。
  - 总导图工具栏与书籍详情显示待复习数。

### 6. 导出
- **PNG 图片**（整张导图，便于直接发给别人）和 **Markdown 大纲**（缩进列表，可导入 XMind 等）。（我的决定）

## 数据（建议，实现者可调整字段名）

全部按 `user_id` 私有。

- `highlights`：id, user_id, book_id, chapter_index, 定位锚点（段落序号 + 段内字符起止）, text（划线原文）, note（批注，可空）, created_at, updated_at。
  - 锚点需在重新渲染、改字号/主题后仍能还原；若原文变化导致锚点对不上，用 text 在本章重新匹配，仍失败则标记为「失效」，在笔记列表中保留显示。
- `mind_nodes`：id, user_id, book_id, parent_id（空 = 挂在章节骨架上）, chapter_index（所属章节）, highlight_id（可空）, label, kind（highlight / event / person / concept / custom）, summary（AI 一句话说明，可空）, note（用户批注）, source（出处：章节 + 段落，可空）, sort, created_at。
  - 骨架节点（书名/分组/章节）不入库，由目录实时生成。
- `ai_expansions`：缓存 AI 展开结果，键 = (book_id, 中心词, 上下文范围)；同一书同一词不重复花钱，可跨用户共享（内容不含个人数据）。
- `quiz_items`：id, user_id, book_id, node_id, question, answer, explanation, stage, due_at, last_result, last_reviewed_at。
- 生命周期与现有书签/进度一致：书籍行在重新扫描时保持不变，笔记随之保留；只有书籍被删除（含文件消失被判为孤儿）时才清理。（我的决定）
- 书籍删除 → 清理以上全部（加入 `relation-cleanup.ts` 的 `BOOK_RELATION_TABLES`）；用户删除 → 清理其 highlights / mind_nodes / quiz_items（加入 `USER_RELATION_TABLES`）。

## AI 调用

- 使用当前选中的 AI 插件的 `chat()`（DeepSeek / MiniMax / Ollama），不新增配置；仅在 AI 已配置时显示「AI 展开」「AI 出题」入口（`/settings/ai-status`）。
- **展开提示词**输入：中心词、所在段落及前后若干段、所在章节标题、书名作者、上一层节点路径（继续展开时）。输出 JSON：`[{label, kind: event|person|concept, summary}]`，5–8 个。解析失败时给出可读错误，不写入任何数据。
- AI 可以使用自身知识进行发散（这正是「学习」的价值），但提示词要求：不编造原文情节、对不确定的知识点标注不确定。
- 防剧透：喂给 AI 的原文只取「阅读边界」之前（与 recap/ask 一致）。阅读边界 = max(该用户保存的 `reading_progress` 位置, 划线自身位置)；从总导图页继续展开时同样按此计算。（我的决定）
- 缓存键（跨用户共享）：(book_id, 中心词, 划线所在 chapter_index)；不含用户的节点路径与阅读边界之外的内容。命中缓存即返回，用户可点「重新生成」覆盖。（我的决定）
- 复习费用：一轮复习的新题**一次 AI 调用批量生成**；选择题本地判分，简答题每题一次 AI 判分。（我的决定）
- 输出去掉 `<think>…</think>`。

## 分期

整体是一个项目，按四期交付，每期可独立验收：

1. **划线与批注**：选区菜单、划线渲染与锚点还原、批注、本书笔记列表、数据表与清理。（TXT / EPUB / UMD）
2. **AI 展开小图**：抽屉/底部面板、候选与保留、继续展开、出处检索与跳原文、展开缓存。
3. **总导图画布与导出**：目录骨架、挂载、拖拽缩放折叠、手动编辑节点、PNG + Markdown 导出。
4. **AI 出题与遗忘曲线复习**：出题、作答判分、阶段与到期、待复习角标。
