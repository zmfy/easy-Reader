# 阅读器 AI 功能：前情提要 + 问书（设计）

单用户自用书房。目标：隔几天回来能快速接上剧情；读到一半能随时问「这个人是谁 / 之前发生过什么」，且不剧透。

## 前情提要
- 触发：打开阅读器时，若距上次阅读（`reading_progress.updated_at`）≥ 3 天，正文顶部显示卡片「上次读到 第 N 章 · X 天前」+「AI 回顾前情」按钮。可关闭。工具栏「前情」按钮随时调出同一卡片。
- 只在点击时调用 AI；结果按 (book_id, chapter_index, paragraph_index) 缓存在 `ai_recaps` 表，同一位置再次回顾直接返回。
- 内容：当前章之前最近 3 章 + 当前章已读部分（按段落序号截取）。每章过长时保留开头与结尾。150–250 字，按时间顺序，不编造、不透露后文。

## 问书
- 工具栏「问书」打开右侧对话面板，可连续提问；对话只在当前页面内保存。
- 防剧透：只使用当前阅读位置之前的内容；提示词明确禁止透露或推测后文。
- 检索（本地、零费用）：从问题中提取 2–6 字的中文词（及英文词），保留在已读正文中出现过的，长词优先；按出现次数给章节打分，取高分章节与每个词首次出现的章节，截取命中处前后片段（总量约 6000 字），再加上当前章已读部分、最近 3 轮对话，一起发给 AI。
- 回答附「参考：第 x 章…」来源。

## 通用
- 仅在 AI 已配置时显示入口（`/settings/ai-status`）。所有登录用户可用（自用）。
- 输出去掉 `<think>…</think>` 等思考内容。
- 书籍删除时清理 `ai_recaps`。

## 不做
- 不把整本书发给 AI；不做向量检索；不持久化问书对话；不自动在打开时调用 AI。
